# Security Policy

## Supported versions

The latest tagged release and `main` are supported.

## Reporting a vulnerability

Please report security issues privately through GitHub Security Advisories if available, or contact the repository owner directly.

Do not include exploit details, cookies, session tokens, or account data in public issues.

## Security notes

- `chatgptbar://` can be triggered by any local process. Automatic sending requires explicit confirmation unless the user enables the setting.
- The distributed app is ad-hoc signed and not notarized. Users should download releases only from this repository's official GitHub Releases page.
